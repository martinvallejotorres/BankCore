# BankCore

BankCore es un sistema bancario básico desarrollado en Java puro con fines educativos.

El proyecto busca aplicar conceptos de Programación Orientada a Objetos mediante la simulación de operaciones bancarias simples.

## Funcionalidades

- Crear clientes
- Crear cajas de ahorro
- Crear cuentas corrientes
- Depositar dinero
- Retirar dinero
- Consultar saldo
- Registrar movimientos
- Bloquear y desbloquear cuentas
- Buscar clientes
- Buscar cuentas
- Listar clientes y cuentas

## Conceptos aplicados

- Programación Orientada a Objetos
- Encapsulamiento
- Herencia
- Polimorfismo
- Clases abstractas
- ArrayList
- UUID
- Relaciones entre objetos

## Estructura principal

- Cliente
- Cuenta
- CajaAhorro
- CuentaCorriente
- Movimiento
- Banco

## Estado del proyecto

En desarrollo.

Actualmente funciona mediante consola y Java puro, sin frameworks ni base de datos.
